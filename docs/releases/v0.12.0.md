Run GitHub commands with one Passlet call, and reuse approved access across sessions without repeated approval prompts.

- Scoped `passlet exec --repos OWNER/REPO --permissions contents:read -- COMMAND` reuses approved access or requests approval when needed. Grants are saved in a private file cache shared by sessions under the same OS user and paired identity. Cached access works while Approver is offline, without extending its scope or expiry. Grants with less than one minute remaining require fresh approval.
- After a command fails, Passlet removes a cached token only when GitHub confirms it is rejected. The next ordinary invocation can obtain fresh approval. Failed commands are never replayed automatically.
- `passlet request` now prints only a receipt by default. Scripts that consume grant JSON must add `--stdout`, or keep using `--out FILE`. Use `--no-cache` with either output option for fresh approval without cache lookup or storage.
- The agent skill uses the single-command workflow, handles recoverable failures quietly, and reads public repositories anonymously without approval.
