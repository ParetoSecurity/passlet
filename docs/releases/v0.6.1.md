Local setup now gets your Agent ready to use Passlet without a separate pairing ceremony. Successful `passlet approver github setup` reuses existing keys, pairs the local Agent, and switches its saved connection to this Mac. Revoked Agents still require explicit pairing.

- Doctor approval dialogs identify the paired Agent requesting the check.
- Pairing instructions show separate commands for the default socket, including SSH-forwarded sockets, and Tailscale. Tailscale discovery failures are reported instead of silently omitting the address.
- `passlet pair` now takes `--endpoint <endpoint>` instead of a positional endpoint. Omit the flag to use the default socket. Update scripts that use the positional form.
- NixOS integration tests exercise local, SSH, and remote TLS pairing, revocation, re-pairing, restart persistence, and invalid or denied invitations.
