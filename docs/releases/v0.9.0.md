Organization members can now complete GitHub setup after an owner approves their app installation, without forwarding localhost callback URLs between machines. Enter the organization's GitHub name, share the approval link with its owner, and click Check approval once approved. Keep the browser tab and `passlet approver github setup` command running until setup completes.

- After setup, drag the Passlet logo into your GitHub App's settings using the new illustrated instructions.
- Nix/Home Manager installations start the Approver at login even before the Nix store is mounted.
- The bundled agent skill now requests missing GitHub permissions directly and offers forwarded SSH access for repositories where you cannot install your GitHub App.

Existing credentials and pairings are preserved. No migration is needed. Resuming an interrupted initial setup after organization approval is not yet supported.
