Use the Tailscale Mac app for remote access with Home Manager, and keep `origin` as the upstream when agents push through Passlet.

- With Home Manager, `programs.passlet.service.tailscale = true` now works with the Tailscale Mac app, so enabling remote access no longer stops Approver from starting. If nix-darwin's `services.tailscale.enable` also installs the standalone daemon, Passlet uses the daemon. See [Tailscale forwarding](https://passlet.dev/docs/getting-started/installation/#configure-tailscale-forwarding).
- The agent skill pushes to `origin` with one-off HTTPS rewrites instead of pushing to a repository URL. Branches keep `origin` as their upstream, so editors such as VS Code no longer offer to publish a branch that was already pushed.
