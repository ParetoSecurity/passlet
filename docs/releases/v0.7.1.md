Passlet now explains socket access failures in coding-agent sandboxes and preserves Git proxy authentication when running commands with scoped credentials.

- HTTPS Approver connections, including pairing, can use an environment-configured proxy while retaining pinned TLS authentication. Unix sockets remain direct.
- Codex connection denials receive sandbox guidance without masking missing sockets, refused connections, or timeouts.
- Doctor treats the default socket on Linux as a forwarded connection and gives SSH troubleshooting advice when it is missing or stale.
- Socket permission errors identify the path and explain that sandbox restrictions may block access even when the Approver is running.
- `passlet exec` preserves Git's proxy authentication method while continuing to replace ambient credential helpers with the scoped Passlet grant.
- Setup documentation covers sandbox socket access, macOS trust-service restrictions, the Tailscale GUI CLI wrapper, shared SSH connections, sandbox resets, and Nix-managed plugin cache conflicts.
