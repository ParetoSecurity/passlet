Install and update the Claude Code and Codex plugins through Home Manager, alongside your Passlet configuration.

- Install Claude Code and Codex plugins through Home Manager with `programs.passlet.plugins.claude-code.enable` and `programs.passlet.plugins.codex.enable`. These options require Home Manager 26.05 or newer. Remove manually configured Passlet marketplace and cache entries before enabling them.
- Agents can use scoped grants with the GitHub API when `gh` is not installed. The bundled skill explains how to use `curl` without exposing the token.
- Test a checkout by stopping the installed service and running the checkout’s `passlet approver start` in the foreground. Use `passlet approver restart` afterward to restore the installed version.

Passlet now requires macOS 26 or later on Apple Silicon. Intel Macs and older macOS versions are no longer supported. Linux Agents remain available for amd64 and arm64.

Existing credentials and pairings are preserved. The macOS download is now named `passlet_0.10.0_macos.zip`.
