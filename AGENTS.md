# Project instructions

Read README.md for project context. Before working in this repository, read and follow `.claude/rules/conventions.md` and `.claude/rules/tooling.md`. Read other files in `.claude/rules` when their path filters match the work.

These rules and the skills in `.claude/skills` come from the pinned `teamniteo/agents` input. If the links are missing or broken, run `nix-shell --run true` to regenerate them. Keep upstream instructions linked rather than copying them into this repository.

Use `skills/passlet/SKILL.md` for authenticated GitHub operations. Its scoped-grant requirements take precedence over upstream guidance about existing GitHub authentication.
