Pair Agents with a one-time command instead of copying public keys into configuration files. Run `passlet approver pair` on your Mac, use the printed `passlet pair` command on the Agent, and approve with Touch ID. Pairing saves the endpoint and trusted keys locally, and survives Home Manager rebuilds.

- Pairing codes expire after ten minutes and work once. Each code pins the Approver's identity before the Agent sends its secret, and every credential request still requires approval.
- List trusted Agents with `passlet approver agents list` and revoke one with `passlet approver agents revoke <name>`. Revocation applies to subsequent requests without restarting the Approver.
- Pairing approval does not unlock provider credentials. Local Agents, SSH-forwarded sockets, and Tailscale all use the same pairing flow and authenticated TLS connection.

Upgrade both the Approver and its Agents. `passlet connect` has been removed. Remove declarative Agent keys, endpoints, and private-key paths from Home Manager, retain installation and service settings, and pair each Agent again, including Agents on the Mac. Existing private keys at the default paths are preserved. See [pairing and migration instructions](https://github.com/ParetoSecurity/passlet/blob/v0.6.0/docs/SETUP.md#pair-agents).
