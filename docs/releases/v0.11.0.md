Linux releases now ship Agent only, and Home Manager installs start cleanly on a fresh machine.

- Linux binaries leave out Approver and are half the size, at 7 MB. `passlet approver` commands on Linux report that they require the macOS build. Packagers building Agent from source can use the same `agentonly` Go build tag.
- Approver starts and creates its pairing key after a fresh Home Manager install. Each activation also repairs existing state directory permissions while preserving credentials.
- Installing from Nix no longer warns about missing metadata files while unpacking release archives.
